# Goal

## Project
ultimate-python — a Python study guide project

## Description
A comprehensive Python study guide featuring standalone, runnable modules that demonstrate Python concepts from basics to advanced topics. Each module contains a `main()` function with examples and assertions that verify correctness. A runner script discovers and executes all modules.

## Scope
- ~40+ production source files organized into four categories:
  - **Syntax basics**: variables, expressions, bitwise operations, conditionals, loops, functions, walrus operator, argument enforcement, template strings
  - **Data structures**: lists, tuples, sets, dicts, comprehensions, strings, deques, namedtuples, defaultdicts, itertools, dict unions, heaps
  - **Classes**: basic classes, inheritance, abstract classes, exception classes, iterator classes, encapsulation
  - **Advanced**: decorators, file handling, context managers, MRO, mixins, metaclasses, threading, asyncio, weak refs, benchmarking, mocking, regex, data formats, datetime, pattern matching
- Test files that verify each module's `main()` function runs correctly
- A runner script that discovers and executes all modules
